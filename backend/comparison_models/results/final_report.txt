EXPLANATION OF MACRO VS WEIGHTED AVERAGE:
================================================================================

MACRO AVERAGE:
   - Calculated by averaging the metric for each class equally
   - Gives equal weight to all classes, regardless of sample count
   - Useful when all classes are equally important
   - If classes are imbalanced, this can be misleading

WEIGHTED AVERAGE:
   - Calculated by weighted average of the metric for each class
   - Weight of each class equals the number of samples in that class
   - Gives more weight to classes with more samples
   - More suitable for imbalanced data
   - Represents the actual performance of the model on the entire dataset

EXAMPLE:
   If Mild class has 100 samples and Severe class has 10 samples:
   - Macro: Both classes get equal weight (50%)
   - Weighted: Mild gets 90% weight, Severe gets 10% weight
